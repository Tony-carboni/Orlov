# Reference files

Things the owner wants kept and handed back on any device (the repo is the shared place; every session pulls it).

- `market-quickbar.txt` — the owner's EVE market quickbar, saved 2026-10-23 in the game's own import format (`+ folder`, `- item`, `++ subfolder`, `-- item`): 12 folders, among them fuel blocks, minerals, ores, filaments, faction tags, Trig materials and a `repro` folder of meta modules. To put it back in the game: copy the whole file, then in the market window's quickbar menu choose Import. Ask any session for "my market quickbar" and it returns the file's contents.
