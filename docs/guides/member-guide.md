# Joining The Orlov Family — how to get set up (for members)

*Post this in `#how-to-auth`. Takes 5 minutes.*

**1. Log in to auth**
Go to **https://auth.orlovfamily.space** → *Log in with EVE Online* → pick your **main** character → Authorize. (This only reads public data.)

**2. Add your other characters (recommended)**
Dashboard → **Add Character** → log out of EVE SSO if needed and log in with the alt → Authorize. Repeat per alt. Then **Change Main** if the wrong one is marked as main.

**3. Link Discord**
Left menu **Services** → Discord → the orange **✓** → Authorize. You're added to the server automatically with the right roles; your nickname becomes `[CORP] Character Name`.

**4. Register in Member Audit (main required, alts welcome)**
Left menu **Member Audit** → **Register** → Authorize with the character. This is the one with the long permission list — it lets leadership see login dates and skills, which is how we keep the roster honest. Nothing can be done *to* your character with it.

**That's it.** Roles update by themselves when you change corp or leave.

**Want to FC?** Left menu **Groups** → *Request* on `FC`. A director approves it; then `#fc-chat` appears for you.

**Something broken?** Ask in `#general` and tag an Alliance Director.
