# Doctrine fitting files

One EVE fittings XML per doctrine, the 15 fits of a doctrine in one file, named `<Doctrine> - <Ship> - <T1/T2>` as the game shows them. Import in game: copy the file into `Documents\EVE\fittings\`, fitting window → Import & Export → Import from file → tick the fits. The same fits are loaded in the Doctrines site (runbook 16).

- `armor-ab-frigs.xml`: AB Armor frigs, 15 fits (2026-10-17)
